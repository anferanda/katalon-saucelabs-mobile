\# Katalon Mobile Automation Project

Repository ini berisi script pengujian otomatis (\*automated testing\*) berbasis mobile menggunakan aplikasi SWAGLAB menggunakan Katalon Studio. 
Project ini memiliki 4 Test Case dan dapat digunakan menggunakan Profiles 'staging'.

\## Struktur Project

\* \*\*Profiles\*\* : Berisi file konfigurasi environment (misalnya: Development, Staging, Production).

\* \*\*Test Cases\*\* : Berisi script pengujian skenario utama.

\* \*\*Test Suites\*\* : Kumpulan skenario untuk dieksekusi otomatis.

\* \*\*Object Repository\*\* : Elemen web/aplikasi yang diidentifikasi.

\* \*\*Data Files\*\* : Berisi data yang digunakan dalam pengujian.

\* \*\*Data\*\* : Berisi apk dari aplikasi mobile.

\## Cara Menjalankan

1\. Clone repository ini: `git clone https://github.com/anferanda/katalon-saucelabs-mobile.git`

2\. Buka Katalon Studio, pilih \*\*Open Project\*\*, lalu arahkan ke folder Android Mobile - Final Project.

3\. Jalankan Test Suite 'Checkout Process'.

4\. Buka Reports untuk melihat hasil pengujian menggunakan test suites.
